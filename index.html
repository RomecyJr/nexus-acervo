Integração

API & dados

Fonte canônica: data/catalog.json. Contrato: schema/catalog.schema.json.

Endpoints previstos

GET /api/v1/items — lista com filtros kind, segment, tag e q.

GET /api/v1/items/:id — item individual.

GET /api/v1/segments — segmentos e contagens.

Consumo estático imediato

Agentes podem ler o JSON bruto autenticando no GitHub privado, ou consumir uma API implantada a partir da especificação OpenAPI incluída.
